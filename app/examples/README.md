# Example images

Three held-out **test-set** images, used only as clickable examples in the demo.

| File | Source | Ground truth | License / attribution |
|---|---|---|---|
| `kermany_pneumonia.jpeg` | Kermany et al., official test set (`person100_bacteria_475.jpeg`) | Bacterial pneumonia | CC BY 4.0 – Kermany, Zhang, Goldbaum (2018), Mendeley Data V2, doi:10.17632/rscbjbr9sj.2 |
| `kermany_normal.jpeg` | Kermany et al., official test set (`IM-0001-0001.jpeg`) | Normal | as above |
| `rsna_lung_opacity.png` | RSNA Pneumonia Detection Challenge, NIH image `00010866_006.png` (in this project's RSNA test split) | Lung Opacity | Data provided by the NIH Clinical Center (https://nihcc.app.box.com/v/ChestXray-NIHCC; Wang et al., CVPR 2017). Annotations: RSNA-STR, Shih et al., Radiology: AI 2019, doi:10.1148/ryai.2019180041 (https://www.rsna.org/artificial-intelligence/ai-image-challenge/rsna-pneumonia-detection-challenge-2018) |

Images were converted to 8-bit grayscale and downsized to at most 768 px.
